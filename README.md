# Thai Realm — ศึกข้ามยุค

เกม MOBA 5v5 ธีมไทย เล่นในเบราว์เซอร์ ไม่ต้องมี server ใช้ GitHub Pages ได้เลย
เวอร์ชันปัจจุบัน (v0.8.0) เล่น **1 คน + บอท 9 ตัว** บนแมพ 3 เลน

## แนวคิดเกม

- **ศึกข้ามยุค:** แมพเปลี่ยนยุคทุก 5 นาที (สุโขทัย → อยุธยา → ยุคสงคราม → ปัจจุบัน) ป้อมเปลี่ยนพฤติกรรมตามยุค และฮีโร่ของยุคนั้นแข็งขึ้น 12%
- **มอนป่า:** จระเข้ยักษ์ งูจงอาง กระสือ กระหัง ฝั่งละ 4 ค่าย ตัวใหญ่ให้บัฟ 80 วินาที เกิดใหม่ตามเวลา บอทมี 1 ตัวต่อทีมที่ตีป่า
- **ชุดใจ:** ก่อนเข้าแมตช์เลือก 1 ใน 4 ชุด (โลภ โกรธ หลง ศรัทธา) แบบเอมเบลม ให้ค่าสถานะ + ราคา + พลังแฝง
- **ฮีโร่ 12 ตัว:** ยุคละ 3 ตัว บทบาทละ 2 ตัว สกิลตัวละ 3 อัน
- **ร้านค้าไอเทม:** ทองใช้ซื้อไอเทม 42 ชิ้นใน 14 สาย (โจมตี ตีเร็ว คมสังหาร ทะลวงเกราะ ดูดเลือด ป้องกัน กำแพงเมือง ชีวิต ฟื้นฟู เคลื่อนที่ มนตรา ทลายค่าย ล่าป่า ทรัพย์) สายละ 3 ชั้นที่อัปเกรดต่อจากชิ้นเดิมได้ ถือได้ 6 ช่อง ซื้อ/ขายได้ที่ฐานหรือตอนตาย เปิดด้วยปุ่ม 🛒 หรือกด B บอทซื้อเองตามบทบาท ค่าไอเทมอยู่ที่ `TR.ITEMS` ใน `js/data.js`
- **สเปลเสริมและกลับพระนคร:** เลือกสเปล 1 จาก 7 ก่อนเริ่ม (กด F) กลับพระนครกด C ร่าย 6 วินาทีถูกขัดได้ น้ำพุทิพย์หน้าฐานฟื้นเลือดเร็ว ค่าอยู่ที่ `TR.SPELLS` / `TR.RECALL`
- **มุมมองแบบ MOBA 3D:** กล้องเอียง (พื้นถูกบีบแนวตั้ง) ฮีโร่ มินเนียน มอนป่าและบอสเป็นโมเดล low-poly 3D หันตามทิศเดิน กดปุ่ม 🎨 ในเมนูเพื่อสลับเป็น 2D คลาสสิก ถ้าเครื่องช้าเกมสลับเป็น 2D ให้เอง
- **กำแพงและบอส:** แมพมีกำแพง/สิ่งกีดขวาง 16 ชิ้นที่หน้าตาเปลี่ยนตามยุค (ตัวละครและมอนเดินทะลุไม่ได้ บอทหาทางอ้อมเอง) และบอสกลางแมพ "ยักษ์วัดแจ้ง" เกิดนาทีที่ 5 ล้มได้ทั้งทีมรับทอง เลเวล และบัฟ 90 วินาที
- **หน้าเลือกตัว 3 มิติ:** ฮีโร่ 12 ตัวเป็นโมเดล low-poly ทำท่าต่อเนื่อง ลากเพื่อหมุนดูรอบตัว ล้อเมาส์/บีบนิ้วเพื่อซูม
- **แมพ 3 เลน:** แต่ละเลนมีป้อม 2 ชั้น (ด่านหน้า → ค่ายกลาง) ต้องพังตามลำดับ ราชธานีโจมตีได้เมื่อค่ายกลางของทีมนั้นพังอย่างน้อย 1 เลน ราชธานีพังแล้วจบเกม

เอกสารออกแบบฉบับเต็มอยู่ในเอกสาร "เอกสารออกแบบเกม MOBA 5v5 ธีมไทย: ศึกข้ามยุค" (Claude Docs)

## กล่องข้อความอัปเดต

กล่องอัปเดตอ่านจาก `TR.CHANGELOG` ใน `js/data.js` ผู้เล่นที่ยังไม่เคยเห็นเวอร์ชันล่าสุดจะเห็นกล่องขึ้นเองตอนเปิดเกม (จำเวอร์ชันที่เห็นแล้วไว้ใน localStorage) และเปิดดูย้อนหลังได้จากปุ่ม "📢 อัปเดต" ที่เมนู

**ทุกครั้งที่อัปเดตเกม ต้องทำ 2 อย่าง:**

1. เพิ่มรายการใหม่ไว้บนสุดของ `TR.CHANGELOG` (version, date, title, items)
2. แก้ `TR.VERSION` ให้ตรงกับเวอร์ชันนั้น

## การควบคุม (v0.8.0)

- ปุ่มโจมตี **Space/J** (กดค้างตีต่อเนื่อง) ปุ่มเล็ก **Z** ตีลูกกระจ๊อก **X** ตีป้อม
- สกิล **Q/E/R** (หรือ 1/2/3) คอมเล็งด้วยเมาส์ได้ มือถือแตะ = ออโต้ ลาก = เล็ง
- **F** สเปล **C** กลับพระนคร **B** ร้านค้า **P/Esc** พัก
- เลเวลขึ้นได้แต้มสกิล กด ▲ บนปุ่มสกิลเพื่ออัป (ตั้งอัตโนมัติได้)
- ตั้งค่าได้ที่ปุ่ม 🎮 ในเมนูหลักหรือเมนูพัก
- ตอนตาย: ลากจอ/แตะมินิแมพเพื่อดูสนามรบ แตะฮีโร่เพื่อติดตาม · ตอนมีชีวิต: แตะ/ลากมินิแมพเพื่อแอบดู
- พุ่มไม้: ยืนในพุ่มเพื่อซ่อนตัวจากศัตรู (เผยตัวเมื่อตี/ใช้สกิล หรือศัตรูเข้ามาใกล้/เข้าพุ่มเดียวกัน)
- ยอมแพ้: เมนูพัก หลังนาทีที่ 8
- เปิดเกมมาเจอหน้าปก ตั้งชื่อแล้วแตะเพื่อเริ่ม (ชื่อจำไว้ในเครื่อง) · `js/net.js` เก็บที่อยู่เซิร์ฟเวอร์ออนไลน์ (`TR.NET.url`) และปลุกเซิร์ฟเวอร์ฟรีล่วงหน้า · มีหน้าโหลด `TR.Loading.show(ข้อความ, %)`
- **Tab** (ค้าง) หรือปุ่ม 📋 ตารางคะแนน · **N** วางตะเกียงส่องทาง · ตอนตายมีสรุปความตาย · เมนูเลือกความยากบอทและเปิดโหมดแบนฮีโร่ (รายชื่อที่บอทอยากแบนอยู่ที่ `TR.BOT_BANS` ใน data.js)
- เสียง: เอฟเฟกต์/เพลงประจำยุค/เสียงประกาศ สร้างสดด้วย WebAudio (ไม่มีไฟล์เสียง) ปรับได้ใน 🎮 ตั้งค่า · โหมดสอนเล่นและสถิติสะสม (📊) อยู่ในเมนูหลัก
- ไอเทมชั้น 3 บางชิ้นเป็นปุ่มกดใช้ (G/H/T/Y) ที่เหลือเป็นพลังแฝง · ฮีโร่ทุกตัวมีพลังติดตัว · สกิลบางตัวเป็นดาเมจเวท (ตัวเลขสีม่วง) ลดด้วยต้านเวท
- สัญญาณทีม: ปุ่ม 💬 หรือกด V แล้วเลือก (หรือกด 1-5) ส่งไปที่จุดที่กล้องมองอยู่ บอทเพื่อนทำตาม
- เลือกเลนได้ในเมนูก่อนเริ่มเกม
- ร้านค้า: จัดเซ็ตไอเทมของฉัน ซื้อก่อน/หลังได้ ไอเทมถัดไปลอยซ้ายจอ และซื้ออัตโนมัติตอนอยู่ที่ฐาน/ตอนตาย

## ตรวจความแน่นอนของเกม (เตรียมออนไลน์)

`node tools/detcheck.js [seed] [วินาที]` รันเกมเดียวกัน 2 รอบด้วยผู้เล่นสคริปต์ แล้วเทียบ hash สถานะทุก 10 วินาทีเกม ใช้เช็กว่าเกมคำนวณผลซ้ำได้ตรงเป๊ะ (ผลเทียบ Node กับ Chromium ตรงกัน) กติกา: ใน `js/sim.js` และ `js/ai.js` ห้ามใช้ `Math.hypot/sin/cos/atan2/random` และ `Date.now` ในตรรกะเกม ให้ใช้ `hyp/dsin/dcos/datan2` และ `g.rand()` แทน ส่วนตัวสุ่มของภาพใช้ `g.vrand()`

## ทดสอบสมดุลด้วยบอท

```
node tools/balance.js 100      # รัน 100 แมตช์ (แมพ 3 เลน ใช้เวลานาน ราวครึ่งชั่วโมงขึ้นไป)
node tools/balance.js 300 42   # 300 แมตช์ เริ่ม seed ที่ 42
```

ผลเป็นตารางอัตราชนะของฮีโร่และชุดใจ และบันทึกที่ `tools/balance-result.json`

**ข้อควรรู้:** บอทไม่ได้เล่นเหมือนมนุษย์ ผลนี้บอกได้ว่ามีตัวเลขที่พังชัดเจนหรือไม่ แต่ไม่ได้รับประกันสมดุลสำหรับผู้เล่นจริง และตัวอย่างน้อย (ฮีโร่ละราว 30 เกม) คลาดเคลื่อนได้ราว ±8%

## สถานะ v0.8.0 (ข้อจำกัดที่ยังมี)

- ร้านค้ามีไอเทมสถานะล้วน ๆ (ยังไม่มีไอเทมใช้งาน/พลังแฝง)
- ยังไม่มีเสียง
- ตัวเลขสมดุลยังไม่นิ่ง และแมตช์บอทต่อบอทบนแมพ 3 เลนยังยาว ดูผลรันบอทล่าสุดได้จาก `tools/balance.js`
- มอนป่ามี 4 ชนิด + บอส 1 ตัว ผู้เล่นข้ามเลนได้อิสระ
- โมเดล 3D เขียนเอง (ไม่พึ่งไลบรารี) ถ้า 3D ทำงานไม่ได้จะถอยกลับไปใช้ภาพ 2D เดิมโดยอัตโนมัติ เอฟเฟกต์ภาพบางอย่าง (เช่นภาพลวงของสกิล) ยังเป็นภาพ 2D
- ยังไม่มีโหมดออนไลน์ (แผนคือย้าย `js/sim.js` ไปรันบน server เกม แล้วให้ client ทำ prediction)
- ยังทดสอบบนมือถือจริงไม่ได้ ทดสอบแล้วเฉพาะเบราว์เซอร์จำลองจอสัมผัส
