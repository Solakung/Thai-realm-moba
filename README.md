# Thai Realm — ศึกข้ามยุค

เกม MOBA 5v5 ธีมไทย เล่นในเบราว์เซอร์ ไม่ต้องมี server ใช้ GitHub Pages ได้เลย
เวอร์ชันแรก (v0.1.0) เล่น **1 คน + บอท 9 ตัว** บนแมพ 1 เลน

## แนวคิดเกม

- **ศึกข้ามยุค:** แมพเปลี่ยนยุคทุก 5 นาที (สุโขทัย → อยุธยา → ยุคสงคราม → ปัจจุบัน) ป้อมเปลี่ยนพฤติกรรมตามยุค และฮีโร่ของยุคนั้นแข็งขึ้น 12%
- **ชุดใจ:** ก่อนเข้าแมตช์เลือก 1 ใน 4 ชุด (โลภ โกรธ หลง ศรัทธา) แบบเอมเบลม ให้ค่าสถานะ + ราคา + พลังแฝง
- **ฮีโร่ 12 ตัว:** ยุคละ 3 ตัว บทบาทละ 2 ตัว สกิลตัวละ 3 อัน
- **ป้อม 3 ชั้น:** ด่านหน้า → ค่ายกลาง → ราชธานี ต้องพังตามลำดับ ราชธานีพังแล้วจบเกม

เอกสารออกแบบฉบับเต็มอยู่ในเอกสาร "เอกสารออกแบบเกม MOBA 5v5 ธีมไทย: ศึกข้ามยุค" (Claude Docs)

## วิธีเล่น

| อุปกรณ์ | เดิน | สกิล | หยุดเกม |
| --- | --- | --- | --- |
| คอมพิวเตอร์ | WASD หรือลูกศร | Q E R หรือ 1 2 3 | P / Esc |
| มือถือ (แนวนอน) | จอยสติ๊กครึ่งจอซ้าย | ปุ่มวงกลมมุมขวา | ปุ่ม ❚❚ |

ตีปกติอัตโนมัติ สกิลเล็งเป้าที่ใกล้ที่สุดให้เอง (ฮีโร่ก่อน แล้วมินเนียน แล้วป้อม)

## ขึ้น GitHub Pages

1. Settings → Pages → Source: **Deploy from a branch** → branch `main`, folder `/ (root)`
2. รอสักครู่ แล้วเปิด `https://<ชื่อผู้ใช้>.github.io/Thai-realm-moba/`

เป็นไฟล์ static ล้วน ๆ ไม่ต้อง build ทดสอบในเครื่อง: `python3 -m http.server 8000` แล้วเปิด `http://localhost:8000`

## โครงไฟล์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html`, `style.css` | หน้าเมนู HUD และกล่องข้อความ |
| `js/data.js` | **ตารางข้อมูลทั้งหมด**: ฮีโร่ สกิล ชุดใจ ป้อม ยุค และประวัติอัปเดต ปรับสมดุลที่นี่ |
| `js/sim.js` | แกนเกม (ไม่แตะหน้าจอ) ตรรกะเดินที่ 20 ครั้งต่อวินาที |

| `js/render.js` | ตัววาดพิกเซล ความละเอียดภายใน 640×360 ขยายเป็นจำนวนเต็ม วาดที่ 60 เฟรมโดยสอดแทรกตำแหน่ง |
| `js/main.js` | เมนู อินพุต ลูปเกม กล่องอัปเดต |
| `tools/balance.js` | รันบอทต่อกันแบบไม่เรนเดอร์ แล้วสรุปอัตราชนะ |

## กล่องข้อความอัปเดต

กล่องอัปเดตอ่านจาก `TR.CHANGELOG` ใน `js/data.js` ผู้เล่นที่ยังไม่เคยเห็นเวอร์ชันล่าสุดจะเห็นกล่องขึ้นเองตอนเปิดเกม (จำเวอร์ชันที่เห็นแล้วไว้ใน localStorage) และเปิดดูย้อนหลังได้จากปุ่ม "📢 อัปเดต" ที่เมนู

**ทุกครั้งที่อัปเดตเกม ต้องทำ 2 อย่าง:**

1. เพิ่มรายการใหม่ไว้บนสุดของ `TR.CHANGELOG` (version, date, title, items)
2. แก้ `TR.VERSION` ให้ตรงกับเวอร์ชันนั้น

## ทดสอบสมดุลด้วยบอท

```
node tools/balance.js 100      # รัน 100 แมตช์ (ราว 7 นาที)
node tools/balance.js 300 42   # 300 แมตช์ เริ่ม seed ที่ 42
```

ผลเป็นตารางอัตราชนะของฮีโร่และชุดใจ และบันทึกที่ `tools/balance-result.json`

**ข้อควรรู้:** บอทไม่ได้เล่นเหมือนมนุษย์ ผลนี้บอกได้ว่ามีตัวเลขที่พังชัดเจนหรือไม่ แต่ไม่ได้รับประกันสมดุลสำหรับผู้เล่นจริง และตัวอย่างน้อย (ฮีโร่ละราว 30 เกม) คลาดเคลื่อนได้ราว ±8%

## สถานะ v0.1.0 (ข้อจำกัดที่ยังมี)

- ยังไม่มีร้านค้า ทองให้ขั้นพลังอัตโนมัติแทน (ทุก 600 ทอง +4% ดาเมจและเลือด)
- ยังไม่มีเสียง ภาพเป็นพิกเซลที่วาดด้วยโค้ดชั่วคราว
- ตัวเลขสมดุลเป็นค่าตั้งต้น ยังไม่นิ่ง (ดูผลรันบอทด้านบน) แมตช์บอทต่อบอทเฉลี่ยราว 27 นาที ยาวกว่าเป้า 15-25 นาที
- ยังไม่มีโหมดออนไลน์ (แผนคือย้าย `js/sim.js` ไปรันบน server เกม แล้วให้ client ทำ prediction)
